## The entry

> Here lies a man who asked, 'what's the worst that could happen?' This.

A one-line tombstone epitaph of famous last words (70 characters). The dying
speech asks the question; the grave itself answers it with a single word.
Black comedy, carved-stone voice, no explanation — the twist lands on the
last word.

## How it runs

`main.py` (Python standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), exactly one
line with no trailing newline, well inside the 150-character gate.
